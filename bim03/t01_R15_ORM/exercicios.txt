### Exercício 4 — Comparar uma operação

Escolha listar tarefas ou inserir uma tarefa. Escreva uma versão em SQL puro e outra em Drizzle. Compare legibilidade, controle, volume de código e proximidade com o banco.

Versão SQL puro:
const resultado = await pool.query(
  `SELECT id, descricao, concluido, projeto_id
   FROM tarefas
   ORDER BY id`
)
const lista = resultado.rows
Versão Drizzle:
const lista = await db.select().from(tarefas).orderBy(tarefas.id)

Legibilidade:
	- Strings com SQL solto no código.	
    - Cadeia fluente e tipada (select().from().orderBy()).
Controle:	
    - Total — você escreve exatamente o que o banco executa.	
    - Menor — o Drizzle decide detalhes da geração.
Volume de código:
	- Com mais itens (string + array de valores + .rows).	
    - Menor e sem mapeamento manual de resultados.
Proximidade com o banco:
    - Máxima — é literalmente a linguagem do banco de dados.	
    - Menor — transforma colunas em objetos JS, mas ainda conceitos do banco (tabelas, orderBy).
